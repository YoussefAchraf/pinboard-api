# et-be documentation

| Document | Audience | Content |
|---|---|---|
| [../README.md](../README.md) | everyone | Overview, feature catalog, API reference, quick start |
| [architecture.md](architecture.md) | engineers | Layers, request lifecycle, patterns, decisions |
| [configuration.md](configuration.md) | engineers, ops | Every environment variable, ports, Docker/compose |
| [features/](features/) | engineers | One page per feature: contract, flow, code map, data, tests |
| [openapi.json](openapi.json) | API consumers | Generated by `npm run docs:export` (not present until the first route ships) |
| [../CHANGELOG.md](../CHANGELOG.md) | everyone | Released changes per version |
| [../AGENTS.md](../AGENTS.md) | contributors (human or AI) | File contract, naming, lint rules |
| [AGENT-NOTES.md](AGENT-NOTES.md), [PROGRESS.md](PROGRESS.md) | internal | Agent working memory and session log |

**Documentation rule:** a feature is not done until its `features/<feature>.md` page is accurate and
`npm run docs:readme` has refreshed the README (enforced by `npm run docs:check` in `npm run verify` and CI).
